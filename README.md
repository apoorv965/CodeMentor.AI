# 🤖 CodeMentor.AI

> **Your AI-powered coding companion for learning, debugging, and improving code.**

CodeMentor.AI is an intelligent web-based platform designed to help developers and students understand programming concepts, analyze code, identify errors, and receive AI-powered guidance. The platform aims to make coding assistance more interactive, accessible, and beginner-friendly.

---

## 🚀 Features

* 🔐 **Google Authentication** – Secure sign-up and login using Google OAuth.
* 🤖 **AI-Powered Code Assistance** – Get intelligent guidance for programming problems.
* 🐛 **Code Debugging** – Identify potential errors and receive suggestions for fixing them.
* 💡 **Programming Explanations** – Understand complex code and concepts in simple language.
* ⚡ **Interactive User Interface** – Clean and responsive interface for a smooth user experience.
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile devices.
* 🔒 **Secure Authentication Flow** – OAuth-based authentication for user access.

## 🔐 Google OAuth Configuration

To enable Google Sign-In:

1. Create a project in Google Cloud Console.
2. Configure the **OAuth Consent Screen**.
3. Create an **OAuth 2.0 Client ID**.
4. Add your local development URL to **Authorized JavaScript Origins**.

Example:

```text
http://127.0.0.1:5500
```

5. Add the authorized redirect URI if required.
6. Copy your Google Client ID and configure it in the project.

> ⚠️ Never expose sensitive credentials, API keys, or secrets in a public GitHub repository.
